# Install order (see README.md for the full sequence):
#
#   pip install torch==2.9.0 --index-url https://download.pytorch.org/whl/cu128
#   grep -vE "^(flash-attn|verl|latex2sympy2)" requirements.txt | pip install -r /dev/stdin
#   pip install verl==0.5.0 latex2sympy2==1.9.1 --no-deps
#   pip install flash-attn==2.8.3 --no-build-isolation
#
# Why --no-deps for verl and latex2sympy2: their setup.py metadata is
# overly restrictive (verl: numpy<2.0.0, tensordict<=0.9.1; latex2sympy2:
# antlr4-python3-runtime==4.7.2) but the original training env actually
# ran with numpy 2.2.6 / tensordict 0.12.2 / antlr4 4.9.3. Bypassing the
# metadata lets us pin the versions that were actually used.
#
# Why --no-build-isolation for flash-attn: its setup.py imports torch at
# build time, but pip's isolated build env can't see the torch we just
# installed in the main env.
# ----------------------------------------------------------------------
